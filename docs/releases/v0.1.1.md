The second release of liman, a small PaaS for a single server. It is
still a **pre-release**: everything below runs in CI on fresh Ubuntu
machines, but liman has not yet run on a real server, behind a real
domain.

## What is new

- **The CLI for macOS.** `liman-darwin-arm64` (Apple silicon) and
  `liman-darwin-amd64` (Intel) come with the release, with checksums and
  build attestations like the Linux files. The daemon stays Linux only.
- **Rootless Podman**, now the default when `limand install` sets up
  Podman: containers run as the `liman` user, under its own Podman, not
  as root. `--rootful` keeps root's Podman. An upgrade keeps the engine
  named in `config.yaml`.
- **A license:** Apache 2.0.
- The release checks that every binary is built for the system and
  architecture its name says.

## Installing

The server, as before:

```
sha256sum --check --ignore-missing SHA256SUMS
gh attestation verify limand-linux-amd64 --repo onrcanogul/liman
chmod +x limand-linux-amd64
sudo ./limand-linux-amd64 install
```

The CLI on a Mac:

```
gh release download v0.1.1 --repo onrcanogul/liman -p liman-darwin-arm64 -p SHA256SUMS
shasum -a 256 --check --ignore-missing SHA256SUMS
gh attestation verify liman-darwin-arm64 --repo onrcanogul/liman
chmod +x liman-darwin-arm64 && sudo mv liman-darwin-arm64 /usr/local/bin/liman
```

The macOS binaries are not notarized by Apple. Downloaded with `gh` or
`curl` they run as they are; one downloaded with a browser has to be
cleared first with `xattr -d com.apple.quarantine liman-darwin-arm64`.

The README's "Installing on a server" has the rest, from the private
network to the first token, and "Podman" the choice between rootless
and rootful.

## Known limits

- Not yet tried on a real server; certificates from Let's Encrypt are
  tested only against Pebble, its test CA.
- The arm64 Linux binaries and the macOS CLI are built and checked for
  their platform, but not run in CI.
- The API has no TLS of its own: it listens only on private addresses
  (WireGuard, for one).
- Configuration and API may still change before 1.0.
